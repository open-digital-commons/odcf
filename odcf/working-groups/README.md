# Working Groups

ODCF's work is organised into four Working Groups (WGs), matching the four pillars of [RFC 001](../RFC-001.md).

| WG | Focus | Page |
|---|---|---|
| 🏛️ WG 1 | Policy, law and international governance | [WG1-policy-law.md](WG1-policy-law.md) |
| 💻 WG 2 | Protocols, architecture and interoperability | [WG2-protocols-architecture.md](WG2-protocols-architecture.md) |
| 🛡️ WG 3 | Civic deliberation, safety and moderation | [WG3-deliberation-safety.md](WG3-deliberation-safety.md) |
| 💰 WG 4 | Economics, funding and anti-capture safeguards | [WG4-economics-funding.md](WG4-economics-funding.md) |

You can join more than one. Many of the hardest questions sit between groups (for example, independence from states involves WG 1 and WG 4), so cross-group discussion is encouraged.

Each WG will select one or two coordinators once it has active members (see [GOVERNANCE.md](../GOVERNANCE.md)).
