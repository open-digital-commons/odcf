# WG 2: Protocols, Architecture and Interoperability

**Status:** Looking for founding members and a coordinator

## Purpose
Work out the technical foundations that make user ownership, portability and algorithmic choice real, and assess whether existing open protocols can provide them.

## Key questions
- Can existing open protocols (ActivityPub, AT Protocol, Matrix, others) meet the principles in RFC 001 §3? Where do they fall short? (Q1, Q10)
- How can identity, content and the social graph be made truly portable, so that users can leave any provider, including ODCF itself? (P1, P8)
- How would an open algorithm marketplace work: publication, auditing, user choice? (Q11)
- How can infrastructure be distributed across jurisdictions so no single state can switch it off? (Q12)
- What does a simple, safe first experience look like for a non-technical user? (Q13)

## First deliverables
1. A **principles-vs-protocols assessment**: a table scoring existing open protocols against principles P1–P10, written with input from those protocols' own communities.
2. A short note on **portable identity** options (for example Decentralized Identifiers and existing protocol-specific approaches).
3. A sketch of the **algorithmic choice** model: what an "open algorithm API" would need to specify.
4. A list of open technical questions that need research funding.

## Useful backgrounds
Distributed systems, protocol design, security and cryptography, identity systems, recommender systems, UX design, experience operating Fediverse or AT Protocol infrastructure.

## A note on attitude
Many people have already built working open networks. This WG should approach them as **partners and teachers**, not as competitors or subjects of evaluation.

## How to join
Introduce yourself in this WG's pinned issue: who you are, what you know, and what you'd like to work on.
