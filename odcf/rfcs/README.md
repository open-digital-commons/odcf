# RFCs

RFCs (Requests for Comments) are proposals for how ODCF should answer a particular question.

| Number | Title | Status |
|---|---|---|
| [001](../RFC-001.md) | The Open Digital Commons Framework | Draft v0.1 |

## Writing an RFC
1. Copy [0000-template.md](0000-template.md) to `0000-your-short-title.md`.
2. Fill it in. Drafts are welcome.
3. Open a pull request. When it is merged as a draft, it receives a number.

## Statuses
- **Draft**: open for discussion.
- **Under review**: considered complete by its authors, being discussed by working groups.
- **Adopted**: incorporated into the framework.
- **Withdrawn / Superseded**: kept for the record.

Competing RFCs on the same question are welcome. Adoption follows the process in [GOVERNANCE.md](../GOVERNANCE.md).
