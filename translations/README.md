# Translations

English is the working language while the framework is being drafted. Translations make the call reachable to far more people, and are one of the most valuable contributions you can make.

Other languages are welcome; open a translation issue to propose one.

## What to translate first
1. `README.md`, the front door
2. `RFC-001.md`, the framework itself
3. `CONTRIBUTING.md`, so people can take part in their own language

## How
1. Open a **Translation** issue saying which language and document you'll work on, so effort isn't duplicated.
2. Create the file in the language folder with the same name as the original, for example `translations/fr/README.md`.
3. At the top, note which version of the English original you translated (for example "Translated from RFC 001 v0.1").
4. Open a pull request. Ideally a second speaker of the language reviews it.

## Principles
- **Meaning over word-for-word accuracy.** Write naturally for readers in your language.
- **Keep terms consistent.** Keep a short glossary (`translations/<lang>/GLOSSARY.md`) for key terms like *commons*, *sortition*, *convener*.
- **The English version is authoritative** while the framework is in draft. If you find something unclear or wrong in the English while translating, please open an issue; translators are often the best editors.
